AI API Key 設定

若想使用你自己的 AI 帳號額度來執行媒合分析、履歷健診、模擬面試與拒絕原因分析，可在下方選擇一個供應商並貼上 API Key。金鑰僅會暫存在本次瀏覽器分頁記憶體（sessionStorage），關閉分頁即清除，不會上傳到任何伺服器。若不設定，工具會繼續使用系統內建連線（僅在支援的環境中可用）。

可在 console.anthropic.com 取得金鑰。使用模型 claude-sonnet-5。

可在 aistudio.google.com/apikey 取得金鑰，支援 AIzaSy 開頭（標準格式）與 AQ. 開頭（新格式）兩種金鑰。提醒：Gemini API 在純前端（瀏覽器直連）環境下偶有 CORS 跨域限制，若連線失敗，工具會顯示原因並建議改用其他供應商。

可在 platform.openai.com/api-keys 取得金鑰。使用模型 gpt-4o。提醒：OpenAI API 在純前端環境下同樣可能遇到 CORS 限制，若連線失敗，請改用其他供應商。
